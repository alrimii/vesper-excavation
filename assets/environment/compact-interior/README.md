# Compact interior asset sources

These are actual downloaded and inspected meshes, adapted for the original place 94763223427049. Source inspection images are geometry renders, not claims about final Roblox appearance. No paid source or installed tools.

| Asset | Author / source / license | Adaptation |
| --- | --- | --- |
| Triceratops horridus skeleton | Smithsonian Institution (NMNHPALEO), [Smithsonian object record](https://www.si.edu/object/nmnhpaleobiology_3572783); [download provider and CC0 statement](https://www.innerscene.com/tools/library/3d-parts/triceratops-skeleton-39cc8434). [CC0](https://creativecommons.org/publicdomain/zero/1.0/). | Original 149,997-triangle scan retained as `source/triceratops.glb`. Stand upright, scale to 38 studs long, simplify to about 45k triangles, partition into four meshes below 20k each, apply a uniform warm fossil finish. No invented bone geometry. |
| Omax compound microscope | [3Donimus on Poly Pizza](https://poly.pizza/m/dcuaH6bEkwn), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). | Original retained. Remove the supplied presentation cube and trailing cable below the instrument base; reduce geometry, ground at zero, scale to 6.5 studs tall. Original material colors retained. |
| Dynamite with Timer | [Hunter Paramore on Poly Pizza](https://poly.pizza/m/0q9sW5qkUuS), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). | Original retained. Scale to 2.1 studs long and center for the existing functional grip; preserve colored materials. This is a game visual only. |
| Selected vegetation | Quaternius Stylized Nature MegaKit Standard FREE, CC0. Exact original files/license in [previous source record](../lab-art/README.md). | Intentional selection: Fern_1, Plant_1_Big, Clover_2, CommonTree_3. Muted compatible colors and varied placement. No KayKit block shrubs, former specimen islands or rejected PlantLeaves clusters retained. |
| Fitted dome panes | Original project geometry, `prepare_assets.py` | New lower pane geometry follows the compact clipped-square room footprint and meets the retained circular crown rim at y247. The original upper crown panes/hoist are retained at their existing dimensions and positions. |

Poly Pizza records include the exact title, author, license, public model ID, download URL, SHA-256 and byte length in the two `source/*-provenance.json` files. The Smithsonian's public search record identifies the linked 3D model and CC0; direct Smithsonian object/page retrieval returned 404/403 during this session, so model bytes were obtained from the explicitly CC0 Innerscene distribution above. This is disclosed source delivery, not a claim of independent museum authentication.

`prepare_assets.py`, `finish_exports.py`, `compact-interior-assets.blend`, `geometry.json` and `exports/` preserve the editable adaptation and actual import inputs. Original downloads are never overwritten. `source-inspection.json` records actual imported mesh topology. All parts are inspected before upload. Actual uploaded IDs and owner metadata are recorded in `asset-manifest.json`. All four active models are approved assets owned by 291892217. The importer omitted material colors and baked a 180-degree Y rotation; `normalize-imports.luau` restores source colors/orientation using measured export bounds. `final-pane-normalization.json` records the final 428-stud enclosure import; the earlier 414-stud pane asset is superseded and removed from the live library and scene. Attribution is also stored on live model and mesh attributes. `refit_enclosure.py` rebuilds only the fitted panes from the canonical geometry recipe.
