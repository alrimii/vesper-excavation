# Outfitter artwork and references

Nine original editable SVG illustrations with 256px RGBA runtime PNG exports: seven actual upgrade categories, credit counter and workshop pickaxe emblem. `build_art.py` preserves vector construction and export steps. No flattened menu background, rejected HUD/tree art, external icon pack, purchased asset, or AI painting is used. The models in product previews and world displays are the existing actual EquipmentAssets, not new advertised tiers. Their art quality remains unapproved; the charge is particularly blocky.

Typography uses Roblox-provided Fredoka One for short labels and Gotham Medium for values/descriptions. No font files were redistributed. Actual returned image IDs and owner are in manifest.json. Upload success does not establish moderation completion, cross-account availability or visual approval.
