Obsolete standalone creation code retired to explicit refusing stubs: `AccessBuilder`, `AccessEndpointRefit`, `AccessPolishBuilder`, `ContinuousAccess`, `ExpandedAccess`, `RoomExperienceBuilder`, `SideWorldPolish`. AccessBuilder's live `ServerStorage.VesperTools` copy matches its stub; the other six were absent from the live authoring inventory. Historical full sources remain only in Git history/private source recovery. Existing `LivingLabBuilder`, `LivingLabArtBuilder` and `OutfitterBuilder` forward scoped calls to `LabInteriorBuilder`; they do not retain competing old architecture constructors.

GUI replacement is scoped to layout: former inset-bound `WorkshopUI` visual Backdrop and SkillTreeUI child background constructor were replaced with shared `ModalLayout.Backdrop` companion ScreenGuis. Existing modal input blockers remain transparent and safe-inset bound. DiscoveryHUD's journal shade now uses the same shared visual background. SecondaryMenus and OutfitterUI use `ModalLayout.FitPanel`. Companion visibility tracks the original modal and is destroyed with its content ScreenGui; no second menu controller or purchase handler was added. Full legacy interface removal belongs to Phase 5.
